# 登記簿OCRアプリ 機能仕様書

## 1. 概要

本ドキュメントは登記簿OCRアプリの機能仕様を定義するものです。このアプリケーションは、紙の登記簿謄本や登記事項証明書をスキャンし、OCR技術を用いてデジタルデータに変換、構造化して管理するシステムです。

## 2. システム要件

### 2.1 基本要件

- **対応OS**: Windows 10/11
- **推奨スペック**:
  - CPU: Intel Core i5相当以上
  - メモリ: 8GB以上
  - ストレージ: 140MB以上（アプリケーション本体）
  - ディスプレイ: 1024×768 フルカラー

### 2.2 入出力要件

- **入力**:
  - スキャンした登記簿画像（JPEG, PNG, TIFF, PDF）
  - 法務省地図XML
  - 登記簿CSV
- **出力**:
  - 構造化されたデータベース
  - 各種帳票（土地登記簿調査表、境界確認書など）
  - CSV/XMLエクスポート

## 3. OCR機能仕様

### 3.1 基本OCR機能

- **文字認識エンジン**: 日本語OCRに最適化されたエンジンを採用
- **認識対象文字**: 
  - 明朝体、ゴシック体の印刷文字
  - 手書き文字（基本的な文字のみ）
- **認識精度**: 95%以上（印刷文字の場合）
- **処理速度**: A4サイズ1ページあたり3秒以内

### 3.2 登記簿専用処理

- **登記簿構造認識**:
  - 表形式データの自動認識
  - 区分所有建物の階層構造認識
  - 権利者情報の抽出
- **データ抽出**:
  - 不動産番号
  - 所在地
  - 地番・家屋番号
  - 地目・地積
  - 所有者情報（氏名・住所）
  - 権利関係情報
- **自動補正機能**:
  - 文字認識エラーの自動検出
  - 辞書ベースの自動修正提案
  - 数値データの整合性チェック

### 3.3 公図処理機能

- **ラスタ→ベクタ変換**:
  - 公図のラスタデータからベクトル変換
  - 自動ポリゴン化
  - 地番認識
- **データ正規化**:
  - 同一点処理
  - 自己交差チェック
  - 重複・空白チェック
  - 合筆処理

## 4. データベース機能

### 4.1 データ構造

- **主要テーブル**:
  - 不動産基本情報
  - 所有者情報
  - 権利関係
  - 履歴情報
- **リレーション**:
  - 不動産と所有者の関連付け
  - 権利関係の時系列管理
  - 公図データとの連携

### 4.2 データ管理機能

- **検索機能**:
  - 地番・家屋番号による検索
  - 所有者名による検索
  - 住所による検索
  - 権利種類による検索
- **更新機能**:
  - データの追加・修正・削除
  - 一括更新処理
  - 変更履歴の管理
- **バックアップ/リストア**:
  - 自動バックアップ
  - 手動バックアップ
  - データリストア機能
